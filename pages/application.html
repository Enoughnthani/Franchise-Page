Application Rules
  • An individual applicant can have more than one application attempt.
  • ID or passport number identifies the person; each attempt keeps its own unique number.
  • Documents from an earlier attempt may be linked to the current application when permitted.
  • A genuine reapplication keeps the earlier attempt visible in history.
Joint Deal Rules
  • Only completed same-franchise applications can be linked into a deal.
  • Each applicant keeps their own application and document history.
  • The linked joint deal owns one transaction for combined affordability and submission.
  • A deal must contain between two and four linked applicants.
